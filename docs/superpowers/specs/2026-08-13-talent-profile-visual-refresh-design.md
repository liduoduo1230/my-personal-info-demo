# 员工信息修改与审核视觉升级设计

## 目标

以用户提供的“人才档案”移动页面为视觉与布局参考，统一员工信息修改页和后台审核页的设计语言。员工端高度还原档案式布局；审核端保留高效的列表加右侧抽屉结构，仅重构视觉层级与抽屉内容布局。

## 设计原则

- 参考图的核心特征是暖米色页面、浅金山水头图、白色大圆角卡片、深棕正文、低饱和金色强调和轻分割线。
- 员工端强调“查看个人档案并就地维护”，后台强调“扫描列表并连续审核”，不为视觉一致性牺牲操作效率。
- 新增、修改、删除、待审核、已通过、已退回均使用文字标签与颜色共同表达。
- 不改变已确认的字段范围、审批规则、整单审核、撤回与自动打开下一单逻辑。

## 员工端（移动端 375px）

### 页面结构

1. 44px 顶部导航，标题为“个人信息”，白色背景。
2. 导航下方设置约 136px 的浅米金山水头图；山形使用代码生成的轻量 SVG，低对比、不承载正文。
3. 头像档案卡悬浮覆盖山水头图底部，宽 343px，白色背景，16px 圆角。花名为主标题，本名为辅助信息，并展示部门、岗位、职级。
4. 档案卡下方设置横向锚点导航，覆盖个人、教育、家庭、履历、银行卡、紧急联系人；支持横向滚动，当前项使用深棕文字和金色短下划线。
5. 所有信息模块在同一长页依次展示。模块为白色 12px 圆角卡片，标题在左，新增或编辑入口在右。

### 信息展示

- 个人基本信息按左右键值行展示；可点击字段保持足够的 44px 热区。
- 教育、家庭和外部工作经历按单条记录形成卡内分组，记录右上角显示编辑入口，模块标题右侧显示新增。
- 银行卡和紧急联系人使用单卡展示，模块标题右侧显示编辑。
- 待审核新增使用浅金虚线边框；待审核修改使用浅金实线与浅暖底；待审核删除降低内容对比度并配删除标签。
- 编辑表单、证明材料、撤回入口延续同一暖色卡片语言；底部固定操作区保留安全区。

### 状态与适配

- 375px 基准画布，内容宽 343px，左右 16px。
- 小于 375px 时内容宽度改为 `calc(100% - 32px)`。
- 锚点导航在窄屏横向滚动，不折行。
- 加载、空、错误、无权限状态使用白色卡片承载；关键可点击区域不小于 44×44px。

## 审核后台（桌面端）

### 页面结构

1. 保留 64px 顶部栏、216px 侧栏、最大 1400px 内容区。
2. 顶部栏改为白色或暖白色品牌导航；主内容标题区加入低对比浅金山水横幅，但不干扰筛选和表格。
3. 待审核、已通过、已退回统计改为白色圆角档案卡，使用细边框和轻阴影。
4. 筛选区与表格置于一个完整白色圆角容器中，表头使用暖灰底，操作仍靠右。

### 审核抽屉

- 保留右侧 640px / 48vw 抽屉和整单“通过 / 退回”。
- 抽屉顶部使用固定标题栏；员工头像、花名（本名）、部门、岗位、提交时间组成档案摘要卡。
- 申请数据用具体模块名称加操作标签作为标题，例如“教育信息  修改”。
- 字段新值为主信息，修改前数据紧随字段下方；新增和删除继续显示明确标签。
- 证明材料、审核结果和退回原因各为独立白色或浅暖色卡片。
- 进入退回状态后，原因输入框和取消、确认退回按钮保持在同一操作容器中。

## 视觉规范

- 页面底色：`#F7F2E8` 附近暖米色；表面：`#FFFFFF`。
- 主文字：沃野 `#3B3431`；辅助文字：`#646A73`。
- 强调：月晖 `#B78F62`；弱强调：`#F5E8C8`；山水装饰采用透明度较低的月晖和曦茶色。
- 成功、警告、危险仍使用语义绿、橙、红，且必须配状态文字。
- 移动卡片圆角 12–16px；桌面容器 8–12px；阴影保持轻量。
- 正文字号移动端 14/22，桌面端 14/22；辅助信息不低于 12px。

## 交互与数据边界

- 本次只调整布局、视觉和滚动锚点，不改变现有领域状态和审批判断。
- 员工端仍不提供审核操作；审核中的信息不可再次提交，撤回仅在编辑详情页。
- 后台仍只允许整单通过或整单退回，处理后自动打开下一条待审核单据。
- 山水图仅作装饰，设置 `aria-hidden`，不影响信息语义和键盘操作。

## 验收标准

- 员工端首屏能够明显识别为参考图同类的档案式布局，并完整展示现有六类信息。
- 后台与员工端共享同一暖米色、白卡、深棕和月晖金视觉语言。
- 原有新增、编辑、删除、提交、撤回、审核、退回流程全部可用。
- 所有现有自动化测试通过，并增加对山水头图、档案卡、锚点导航和后台档案式视觉结构的契约测试。
- 页面在 375px 移动视口与 1440px 桌面视口无横向溢出（表格内部滚动除外）。
